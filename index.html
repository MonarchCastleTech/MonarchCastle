02 — Spearhead · Defense Intelligence

BNTI reads the walls in real time, and only speaks when it is sure.

The Border Neighbor Threat Index watches news and wire feeds across Türkiye's seven land neighbors and resolves them into one composite a commander can act on.

Open repository ↗
The judgment

One composite, three thresholds.

A 1–10 index per neighbor, weighted into a single national reading and banded Stable, Elevated or Critical. The Critical band — and only the Critical band — is allowed to be red.

The model

The LLM attributes. It never scores.

A language model is used strictly to attribute and categorize headlines. The weight each event carries is set by a fixed, deterministic model — so the judgment is auditable, not an opinion you cannot inspect.

The horizon

A 48-hour trend, and a bounded forecast.

Each reading carries its recent trajectory and a short-horizon projection — enough to see a situation moving before it arrives, not a promise dressed as certainty.

05 — Methodology

How a BNTI reading is built, in order.

This genuinely is a sequence. Each step is exact, and each one can fail closed — which is why the number at the end is one you can stand behind.

  1. 01 Collect Regional news and wire feeds across the seven border neighbors are gathered continuously, with coverage tracked per source.
  2. 02 Attribute An LLM attributes each headline to a neighbor and an event category. This is the only place a model exercises judgment — and it never assigns weight.
  3. 03 Score A fixed, deterministic model assigns each attributed event its weight. The same evidence always produces the same score.
  4. 04 Calculate Per-neighbor scores are combined into a single weighted composite on a 1–10 scale.
  5. 05 Threshold The composite is banded Stable, Elevated or Critical against fixed cut points — no discretionary smoothing.
  6. 06 Brief A regional brief and a 48-hour trend with forecast are generated to accompany the number, so the reading arrives with its context.
  7. 07 Publish gate Only if coverage, attribution and summary generation all validate does the snapshot publish. Otherwise the last good public reading stands.
